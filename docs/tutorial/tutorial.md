# Tutorial

This tutorial is the starting point for **new users** of the battery data space in the
HZB NOMAD Oasis. It shows how to document your battery research in NOMAD: from the
chemicals you buy, via the materials and stocks you prepare, to the assembled cell and
its measurements.

## What you will learn

- How the documentation of a battery cell is organized in NOMAD: which entries exist and
  in which order you create them.
- Where to start: creating a project and the first entries in it.
- How to link entries, so that every cell can be traced back to the materials it was
  made from.
- How to attach measurement data and how to find your entries again.

## Before you start

- You need an account for the HZB NOMAD Oasis.
- No programming is needed. All entries are created and edited in the web interface
  (ELN = electronic lab notebook).
- It helps to have the data of your samples at hand: names and IDs, suppliers, masses,
  dimensions, and so on. Fields you do not know yet can be left empty and filled later.
